### 🚀 About Me

I am a **Robotics and Automation Engineer** dedicated to engineering high-performance autonomous systems, robotic middleware architectures, and physics-based simulations. My work bridges algorithm development with embedded hardware execution—from reinforcement learning policies to real-time microcontroller firmware.

- 🎯 **Core Focus:** Autonomous navigation, ROS 2 software stacks, multi-agent reinforcement learning, and embedded control loops.
- 🔬 **Current Research:** Multi-agent autonomous vehicle racing using PPO and MuJoCo.
- 🛠️ **Hardware Interfacing:** Real-time sensor-actuator firmware on ESP32, Arduino, and PIC microcontrollers.
- 📐 **Mechanical & CAE:** CAD modeling in SolidWorks and structural/thermal finite element analysis in ANSYS.

### 🏎️ Featured Project

#### **Multi-Agent Autonomous Racing using PPO and MuJoCo**
> *High-speed competitive multi-agent vehicle control via Proximal Policy Optimization in physics-accurate simulation.*

- **Continuous Control & Policy Optimization:** Trained deep reinforcement learning policies with **PPO** for dynamic line tracking, aggressive overtaking, and slipstream utilization.
- **Physics Engine:** Simulated rigid-body kinematics, tire-road contact friction, and aerodynamics inside **MuJoCo**.
- **Multi-Agent Interaction:** Implemented decentralized observation spaces enabling collision-free multi-vehicle competitive racing.
- **Stack:** `Python` • `MuJoCo` • `PyTorch / RL` • `Gymnasium`
